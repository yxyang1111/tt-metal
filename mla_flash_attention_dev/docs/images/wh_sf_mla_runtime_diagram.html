Wormhole B0 — SF-MLA 数据流架构图（4-core S block）

逻辑坐标系 8×7 · 6 S blocks × 4 cores = 24 active · 6 DRAM banks · NOC0 torus

① K DRAM → sender（NCRISC）
② K multicast sender → block（BRISC）
③ Q broadcast output → all workers（BRISC）
④ TRISC compute（QK^T → softmax → P·V）
⑤ tree reduction → S1 output（BRISC）
⑥ final output → DRAM（writer）
图例说明：
· 每个彩色虚线框是一个 S block（2×2 = 4 core），框色与绑定的 DRAM bank 颜色对应。
· 灰色方块是 8×7 逻辑网格中未被 S block 使用的 inactive core。
· 每个 S block 的第一个 core 标有 SENDER，负责从绑定 DRAM bank 读 K 并 multicast。
· S1 的 4 个 core 同时是 output core，持有 Q 并写最终输出。
· 红线 ①：K 从 DRAM bank 读到 sender（NCRISC）。
· 黄线 ②：sender 把 K multicast 到同 block 内其它核（BRISC，NOC0）。
· 青线 ③：Q 从 S1 output core 广播到所有 worker core（BRISC，各 core 从 S1 L1 pull）。
· 绿色：每个 core 上的 TRISC 并行执行 flash attention chunk compute。
· 紫色虚线 ⑤：tree reduction（S2→S1, S4→S3, S6→S5, 然后 S3→S1, S5→S1）。
· 粉线 ⑥：最终结果从 S1 output core 写回 DRAM。

数据流顺序： ①DRAM→sender → ②sender multicast→block → ③Q broadcast → ④chunk compute → ⑤tree reduction → ⑥output write
