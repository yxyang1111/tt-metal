# Capability Probe 汇总

说明：这里汇总 strict four-way capability probe 的结果，用来筛出四种 decode 方法共同支持的公共参数空间。
说明：逐 case 明细仍保留在 `capability_probe.md`；这里优先展示支持边界与失败模式。

## 1. 总览

| 指标 | 当前值 | 说明 |
|---|---|---|
| status | `completed` | `completed` 表示 probe 已全部跑完；否则当前为 checkpoint 快照 |
| probe preset | `wide_bh_full` | 本次 probe 使用的 preset |
| device arch | `wormhole_b0` | probe 结果对应的设备架构 |
| all four ok | `800/1000` | 四种 decode 方法都可运行的 case 数量 |
| all four ok ratio | `80.0%` | 四方法公共支持比例 |
| baselines | `reference_attention, flash_attention, flash_mla, deepseek_flash_mla` | 本次 probe 检查的 baseline 集合 |

## 2. 共同支持边界（按 `B × H`）

- `B=1`: 四方法全支持 `H=8 / H=16 / H=24 / H=32`；不支持 `无`。
- `B=2`: 四方法全支持 `H=8 / H=16 / H=24 / H=32`；不支持 `无`。
- `B=4`: 四方法全支持 `H=8 / H=16 / H=24 / H=32`；不支持 `无`。
- `B=8`: 四方法全支持 `H=8 / H=16 / H=24`；不支持 `H=32`。
- `B=16`: 四方法全支持 `H=8`；不支持 `H=16 / H=24 / H=32`。
