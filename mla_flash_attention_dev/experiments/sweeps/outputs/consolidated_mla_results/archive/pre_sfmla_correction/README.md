# Pre-S-FMLA-Correction Archive

This folder contains superseded uncorrected S-FMLA result files.

Current files in `consolidated_mla_results/` use corrected S-FMLA latencies by default for both decode and prefill. Going forward, references to S-FMLA in reports and plots should use the current corrected files, not the archived `_origin` files here.

The archived `viz/` subfolder contains old plots generated from the pre-correction data.
